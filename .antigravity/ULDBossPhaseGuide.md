## 二、7 大核心 Boss 逐个实战阶段指南

### 1. 拆解者 XT-002 (XT-002 Deconstructor)
> **阶段划分**：P1 常规本体 -> 75%/50%/25% 露出心脏（打爆进入 H 模式碎心狂暴）  
> **站位图推荐**：**单图呈现**

#### 机制与站位指南
1. **主坦位置**：在 12 点正北背靠北墙拉怪，使 BOSS 背对全团，防止正面震耳发聩与顺劈波及大团。
2. **近战站位**：集中在 BOSS 正背后 6 点脚后跟输出，严禁走到龙头两侧。
3. **远程与治疗**：在南半场呈大扇形分散（每人间距 10 码以上），覆盖两侧出怪门。
4. **核心动态跑动（白右黑左）**：
   * 点名**发光炸弹（白光）**：立刻向右侧（东面）空地狂奔出人群；
   * 点名**重力炸弹（黑光）**：立刻向左侧（西面）空地狂奔出人群，绝不可吸附大团。
5. **小怪处理**：发条机器人与废料机器人从东西两侧通道涌入，猎人冰霜陷阱减速，远程第一时间转火击杀。

### 2. 钢铁议会 (Assembly of Iron - 困难模式)
> **阶段划分**：P1 三首领 -> P2 击杀符文大师后双首领 -> P3 击杀唤雷者后破钢者极度狂暴  
> **站位图推荐**：**单图呈现（起手三分怪开局站位）**

#### 机制与站位指南
1. **三分怪起手布局**：
   * **破钢者（大怪）**：主坦拉在正北靠墙，保坦奶骑紧跟其后 20 码（注意融化之拳秒坦，大光与牺牲不断）；
   * **唤雷者（中怪）**：副坦 A 拉在东侧，远离大团 25 码以上，读条【超载】时周围近战必须撤出 20 码规避；
   * **符文大师（小怪）**：副坦 B 拉在中偏西，全团近战与远程起手第一目标集火秒杀。
2. **符文机制**：
   * 地面刷新**蓝色增伤符文**：全员（除主坦外）迅速踩入获得 50% 伤害加成；
   * 地面刷新**绿色死亡符文**：坦克必须第一时间拉走 BOSS，近战迅速后撤。
3. **P3 破钢者斩杀**：
   * 破钢者获得【压倒能量】，输出提高 200%，25 秒后被点名坦克必死爆炸，副坦需在最后 2 秒提前嘲讽接手；
   * 全团开英勇/嗜血在坦克死绝前极限 RUSH。

### 3. 霍迪尔 (Hodir - 3分钟速通 H 模式)
> **阶段划分**：极寒叠层取暖与吃 Buff 增伤阶段 <-> 闪霜大落冰规避阶段  
> **站位图推荐**：**单图呈现（中央火堆轴心）**

#### 机制与站位指南
1. **火堆轴心原则**：法师 NPC 被救出后会在中场升起【暖炉火堆】，全团远程与治疗严密围拢在火堆 10 码内，消除极度寒冷层数并获得爆击加成。
2. **坦克与近战**：坦克将霍迪尔定在火堆北侧 10 码处背对人群，近战在 BOSS 脚跟输出并蹭火堆 Buff。
3. **增益传导链**：
   * 萨满 NPC 提供【风暴之力】（雷云），中雷云的玩家第一时间跳进火堆人群，为所有法系传导 100% 暴击伤害；
   * 德鲁伊 NPC 降下日光/星光，远程法系尽量站在光柱中输出（急速提高 100%）。
4. **闪霜（大落冰）**：
   * 地面先出现小冰圈，所有人避开；随后出现大落冰砸出雪堆；
   * 霍迪尔读条闪霜结束前，**所有人必须站上积雪雪堆**，否则被冰冻并被秒杀。躲完立刻回火堆。

### 4. 托利姆 (Thorim - 困难模式)
> **阶段划分**：**P1 内外场分兵作战 -> P2 托利姆跳入竞技场斩杀**  
> **站位图推荐**：**双 Tab 站位图（强烈推荐）**

#### 【Tab 1: P1 阶段·内外场双线分兵】
* **外场防守大团**（1坦 + 2~3奶 + 远程与部分近战）：
  * 竞技场主坦在中央圆圈聚拢刷新的人类/矮人小怪；
  * 治疗与远程在竞技场中外圈分散站位，严禁扎堆防西芙【暴风雪】减速；
  * 严禁站在王座充能圆盘的正前方扇形区域。
* **内场通道突破组**（1副坦 + 1奶骑 + 核心近战/狂暴战/盗贼/爆发远程）：
  * 迅速破门进入通道，沿走廊向王座冲锋；
  * 规避旋转刀刃机关，集火击杀铁符文侍从与符文巨灵；
  * 必须在 **2 分 45 秒内** 冲到王座触发托利姆，否则外场将被西芙暴风雪全灭。

#### 【Tab 2: P2 阶段·竞技场全员斩杀】
* 托利姆跳入竞技场，内场组与外场组瞬间在竞技场内合流。
* **致命核心【闪电充能】**：
  * 托利姆面朝某一扇形墙角引雷，充能后对该扇形半场释放高额电击；
  * **全团必须看清 BOSS 面向，统一向左或向右半场快速转移避让**！
* **分散站位**：近战与远程相互保持 8 码分散，防止【连锁闪电】减员。
* **双坦换嘲**：托利姆释放【失衡打击】（使当前坦受物理伤害提高 200%），副坦必须在 15 秒内迅速嘲讽换坦。

### 5. 弗蕾雅 (Freya - 三长老存活)
> **阶段划分**：**P1 三波怪轮换刷新与回血大树 -> P2 弗蕾雅狂暴斩杀大风筝**  
> **站位图推荐**：**双 Tab 站位图（推荐）**

#### 【Tab 1: P1 阶段·小怪轮换与控血】
* **主坦站位**：在生命温室正北水池边拉住弗蕾雅，使其背对全团。
* **三类小怪轮换应对**：
  1. **爆裂水灵波**：坦克拉住聚怪，残血必须全团分散并同时击杀，防止自爆瞬间炸死大团；
  2. **三元素波（水灵/树人/风暴）**：**必须控血并在 12 秒内同时击杀**，否则互相满血复活；
  3. **远古水灵/古树波**：全团站在健康蘑菇下消除沉默，大地震颤读条时全员停手断条。
* **头号转火目标**：场上刷新【艾欧娜尔的礼物】（回血大树），所有 DPS 第一优先级秒杀，否则 BOSS 持续巨额回血。

#### 【Tab 2: P2 阶段·水池沿岸大风筝】
* 弗蕾雅进入斩杀阶段，不再刷新小怪。
* 地面频繁掉落【自然之怒】（阳光炸弹种子），几秒后爆炸造成巨额伤害。
* **全团大走位**：主坦拉着弗蕾雅沿温室水池外围顺时针或逆时针持续大移动风筝，近战贴身走位，远程与治疗跟随大部队边走边打。

### 6. 米米尔隆 (Mimiron - 救火 Hard Mode)
> **阶段划分**：**P1 烈焰战车 -> P2 VX-001 炮台 -> P3 空中指挥艇 -> P4 机械三合一合体**  
> **站位图推荐**：**三至四 Tab 站位图（最复杂首领，强烈推荐）**

#### 【Tab 1: P1 阶段·战车与地雷】
* 主坦将战车定在中场偏北背对全团；
* 近战脚后跟输出，严禁触碰战车排出的【感应地雷】；
* 副坦与远程四散站位，躲避【等离子冲击】与【凝固汽油弹】，灭火组水球迅速灭火。

#### 【Tab 2: P2 阶段·激光扫射大走位 (灭团最高发)】
* BOSS 升上中央平台，无仇恨。
* **灭团杀手【P3Wx2激光弹幕】**：
  * BOSS 读条 4 秒后，进行 **360° 顺时针旋转喷射超高温激光**，扫到即秒；
  * **站位图核心**：标明全团统一按**顺时针大圈同向跑动避让安全路线**，严禁逆行与掉队；
  * 平时全团分散站位，规避红圈火箭打击。

#### 【Tab 3: P3 阶段·空中指挥艇与突击怪】
* BOSS 飞机头飞在空中，常规近战打不到，由猎人/术士/鸟德等远程主打；
* **突击机器人**：防骑第一时间拉住并背对人群；击杀后掉落【磁力核心】，指定队员捡起核心丢在飞机头正下方，将飞机头吸到地面昏迷易伤，近战立刻一拥而上打爆发；
* **炸弹机器人**：远程冰霜减速风筝击杀，严禁进近战堆自爆；
* **灭火机器人**：由副坦或群控职业带走。

#### 【Tab 4: P4 阶段·三合一合体与均血同死】
* 底盘（战车）、躯干（炮台）、头部（飞机头）合体为巨型机甲。
* **终极痛点【修血同死】**：
  * 三个部位的生命值必须平均修血，**必须在 15 秒内同时打爆**！只要有一个部位先死，15 秒后就会满血复活导致团灭；
  * **分工站位**：近战组主打底盘与躯干，远程组主打头部并随时停手修血；
  * 依然保持走位避开激光扫射与地雷。

### 7. 维扎克斯将军 (General Vezax - 暗影无面者)
> **阶段划分**：P1 将军本体绝望光环阶段 -> 萨隆邪铁畸体合成阶段（困难模式）  
> **站位图推荐**：**单图呈现（经典两组黑水与脚跟站位）**

#### 机制与站位指南
1. **绝望光环**：全场无法通过常规手段自然回蓝，治疗只能打破萨隆邪铁蒸汽吃绿水回蓝（但叠层高会掉血）。
2. **两组重叠抱团战术**：
   * 远程与治疗绝对禁止自由散开！必须严格分成 **A 组（西南）** 与 **B 组（东南）** 两个紧密重叠点；
   * 地面刷新萨隆邪铁黑水时，对应组踩入获得【+100%法术急速、-75%耗蓝】狂暴输出。
3. **近战重叠卡位**：近战全体严格重叠在将军正脚后跟输出，绝不出圈，避免被点名暗影印记。
4. **暗影印记逃逸路线**：
   * 任何远程被点名【无面者的印记】，必须在 **1 秒内独自向正南（6点钟）空地反向狂奔**，严防吸大团的血灭团。
5. **暗影冲击规避**：将军朝远程组丢黑球，该组全员瞬间向侧面横移几步规避爆炸。
6. **H 模式畸体处理**：不打碎蒸汽，第 6 块蒸汽合成【萨隆邪铁畸体】后，副坦拉在将军旁边，全团转火秒杀畸体，最后斩杀将军。大团站位全程无需改变。

## 三、站位图系统多阶段落地方案 (技术实现规范)

借鉴成熟的 Tab 切换架构，多阶段首领站位图的底层实现设计如下：

```lua
-- 数据层：多阶段 Boss 配置示例
RaidMap.RegisterBoss({
    id = 9,
    name = "托利姆",
    phases = {
        [1] = {
            tabName = "P1·内外场分兵",
            mapTex = "Interface\\AddOns\\BGLite_Plus\\Media\\icon\\ULDtitan\\m9.png",
            tacticTip = "【P1要点】外场中圈分散防暴风雪；内场突破组破门冲锋2分45秒内触发王座！",
            targets = { ... }, -- 走廊入口、竞技场中圈、西芙暴风雪
            buildSpots = function(...) ... end,
        },
        [2] = {
            tabName = "P2·竞技场斩杀",
            mapTex = "Interface\\AddOns\\BGLite_Plus\\Media\\icon\\ULDtitan\\m9.png",
            tacticTip = "【P2要点】托利姆下地！看清闪电充能面向，全员左右换边避让；分散防连锁闪电！",
            targets = { ... }, -- 托利姆本体、充能扇形警戒区、换边避让箭头
            buildSpots = function(...) ... end,
        }
    }
})
```

### 核心亮点：
1. **智能 Tab 栏**：单阶段 Boss（拆解者、议会、霍迪尔、将军）隐藏 Tab 栏，保持界面干净；多阶段 Boss（托利姆、米米尔隆、弗蕾雅）顶部自动呼出 `[P1阶段] [P2阶段]` 切换按钮。
2. **人员数据无损继承**：切换阶段 Tab 时，已分配的玩家阵容不重置，平滑映射到当前阶段对应的战术编号上。
3. **独立阶段广播**：团长灭在哪个阶段、需要讲哪个阶段，就切到该 Tab 一键将该阶段的战术与跑位广播到团队频道。
